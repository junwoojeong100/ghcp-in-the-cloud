## Source and publication

The source files are `slides/GHCP_in_the_Cloud_Demo_KO.pptx` and `en/slides/GHCP_in_the_Cloud_Demo_EN.pptx` in this repository. Cloning the repository includes both decks, about 101 MB in total. The videos are embedded in the PPTX files and play without separate video files.

The `Pages` workflow copies the repository PPTX files to the site root, and the Office web viewer opens those published copies. The existing PPTX assets of the release [`recorded-demo-slides`](https://github.com/junwoojeong100/ghcp-in-the-cloud/releases/tag/recorded-demo-slides) are distribution copies; the full English MP4 is also in that release.

## Before you present

1. Open the repository PPTX in the language you will present with PowerPoint. Press ▶ on a slide to check each video's picture, sound and playback.
2. For the order of a live demo, the Full and Lite courses and the checklist, follow [`en/DEMO_GUIDE.md`](../DEMO_GUIDE.md). The step-by-step commands and success criteria are in [`en/demos/`](../demos/).
3. The deck shows the screens captured when the demos were recorded. Rehearse a live demo with your own subscription and permissions using the current demo guides.

## Updating and publishing

Edit the repository PPTX files and submit them in a PR for review and merge to `main`. Changes to either deck trigger `Pages` automatically. Follow [`en/slides/VIDEO_GUIDE.md`](VIDEO_GUIDE.md) for recording preparation, video replacement and publication steps.
