## 원본과 게시 위치

원본은 이 저장소의 `slides/GHCP_in_the_Cloud_Demo_KO.pptx`와 `en/slides/GHCP_in_the_Cloud_Demo_EN.pptx`입니다. 저장소를 clone하면 두 덱도 함께 받습니다. 합계 약 101 MB이며 영상이 PPTX 안에 포함되어 있으므로 별도 영상 파일 없이 재생할 수 있습니다.

`Pages` 워크플로는 저장소의 PPTX를 사이트 루트로 복사해 게시하고, Office 웹 뷰어는 이 게시 사본을 엽니다. 릴리스 [`recorded-demo-slides`](https://github.com/junwoojeong100/ghcp-in-the-cloud/releases/tag/recorded-demo-slides)의 기존 PPTX는 배포 사본이며, 전체 영문 영상(MP4)도 해당 릴리스에 있습니다.

## 발표 준비

1. 저장소에서 발표할 언어의 PPTX를 PowerPoint로 엽니다. 슬라이드의 ▶를 눌러 영상의 화면·소리·재생을 확인합니다.
2. 직접 시연할 때의 순서, Full·Lite 코스와 체크리스트는 [`DEMO_GUIDE_KO.md`](../DEMO_GUIDE_KO.md)를 따릅니다. 단계별 명령과 성공 기준은 [`demos/`](../demos/)에 있습니다.
3. 녹화 덱은 녹화 당시의 실행 화면입니다. 내 구독과 권한에서 직접 시연할 때는 현재 데모 문서대로 리허설합니다.

## 수정과 게시

저장소의 PPTX를 수정해 PR로 검토받고 `main`에 반영합니다. 두 덱 중 하나가 바뀌면 `Pages` 워크플로가 자동 게시합니다. 녹화 준비, 영상 교체와 게시 절차는 [`VIDEO_GUIDE_KO.md`](VIDEO_GUIDE_KO.md)를 따르세요.
