# 데모 영상 녹화·PPT 삽입 안내

## 목표와 현재 상태

이 안내는 GitHub와 Azure에서 실제 실행한 데모를 여섯 개의 독립된 영상으로 녹화하고, 해당 영상을 발표 자료에 넣는 절차입니다. 현재 저장소에는 녹화 영상이 없으며, 실제 GitHub 조직과 Azure 구독에서 실행한 화면도 포함되어 있지 않습니다. 따라서 생성한 PPTX에는 영상 대신 녹화 위치 안내가 표시됩니다. 실제 실행을 마친 뒤 영상 파일을 넣어야 재생할 수 있습니다.

각 데모의 클릭 경로, 명령, 성공 기준은 링크된 데모 안내를 따릅니다. 발표 대본과 녹화 큐는 PPTX의 발표자 노트에도 있습니다.

## 녹화 전 준비

1. 저장소 루트의 `README.md`와 촬영할 데모의 안내를 따라 데모 환경을 구성하고, 전체 순서를 한 번 리허설합니다. GitHub·Azure 리소스 생성과 배포는 각 안내의 권한, 비용, 정리 절차를 확인한 뒤 진행합니다.
2. 발표용 브라우저 프로필과 터미널을 준비하고 알림을 끕니다. 화면 배율과 글꼴 크기를 읽기 쉽게 설정합니다.
3. 실사용 자격 증명과 개인 정보가 화면·음성·알림에 들어가지 않도록 확인합니다. `DEMO_PASSWORD`, 토큰, `Authorization` 헤더, 키, 비밀 값, 민감한 리소스 식별자를 표시하거나 말하지 않습니다. 기록된 파일을 발표에 쓰기 전에 전체 화면과 오디오를 다시 확인합니다.
4. 화면 녹화 도구에서 16:9 화면 전체와 마이크를 선택합니다. 영상 편집 시 데모 동작과 성공 기준이 끊기지 않도록 하고, 대기 구간은 짧게 편집하되 실제 결과를 대체하거나 꾸미지 않습니다.

## PPTX에 넣기

1. 저장소 루트에서 `slides/videos/` 폴더를 만들고 위 표의 파일을 해당 이름으로 저장합니다. 영상은 MP4여야 하며, 이름은 바꾸지 않습니다.
2. `python slides/build_deck.py`를 실행합니다. 영상이 있는 데모마다 가치·시연 흐름·영상·핵심 코드 순서로 별도 재생 슬라이드가 만들어집니다. 파일이 없는 경우 해당 슬라이드에 파일 경로 안내가 남습니다.
3. 생성된 `slides/demo-presentation-ko.pptx`를 PowerPoint에서 열어 각 영상의 재생, 화면 비율, 소리, 자막·민감 정보 노출을 확인합니다. 생성 결과는 저장소의 대용량 파일 정책에 맞춰 관리합니다.

실제 영상을 녹화하지 않은 상태에서 mock 응답이나 정지 화면을 실제 GitHub·Azure 실행 결과처럼 제시하지 않습니다. 오프라인 mock 영상이 필요하면 영상 제목과 설명에 mock 모드임을 분명히 표시합니다.
